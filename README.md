# dataset_TC

Датасет: распознавание топологического заряда искажённого вихря
Здесь считается острая фокусировка (интеграл Ричардса–Вольфа) оптического вихря
с круговой поляризацией. В вихрь внесено искажение: секторная диафрагма
(см. Stafeev, Beldinova, Kotlyar, Opt. Commun. 620, 133642 (2026)). Задача —
по картине интенсивности в фокусе определить топологический заряд (ТЗ) m.

Файлы
Файл	Назначение
RichWolf.m	Базовый класс: константы, параметры линзы и расчётной области, расчёт и вывод интенсивности и вектора Пойнтинга
debay2DGeneral.m	Подынтегральные выражения Ричардса–Вольфа (матрица преобразования поляризации линзой, вихревой множитель `exp(imphi)`)
circularPar.m	Входной пучок с однородной поляризацией (`'right'`, 'left', 'linear x', 'linear y'`); численное интегрирование `integral2 по точкам сетки
main.m	Расчёт и вывод одной картины интенсивности
generate_focus_noise_dataset.m, generate_focus_noise_labeled_dataset.m	Первая попытка: зашумлённые копии одной картины на класс (m, delta)
generate_tc_dataset.py	Генератор датасета: 4 ТЗ × 500 изображений
Основные переменные
Переменная	Смысл
lambda	длина волны, мкм (0.633 — He-Ne лазер)
kWave	волновое число 2*pi/lambda
NA	числовая апертура линзы; задаёт thetaMax = asin(NA/refrMedia)
refrMedia	показатель преломления среды (1 — воздух)
thetaMin, thetaMax	пределы интегрирования по полярному углу (кольцевая апертура, если `thetaMin > 0`)
alphaMin, alphaMax	пределы по азимуту. [delta/2, 2*pi - delta/2] — это и есть секторная диафрагма шириной delta
apodizationType	функция аподизации: 'aplanatic' → sqrt(cos(theta))
mode	амплитуда входного пучка (`'plane'` — плоская волна)
mVortex (`mVort`)	топологический заряд вихря — метка класса
delta	угловая ширина непрозрачного сектора, рад — величина искажения
aCircE, bCircE	вектор Джонса входного поля (a, b): (1, i) — правая круговая
aCircH, bCircH	то же для магнитного поля
rMin, rMax, rNum (`discretization`)	окно расчёта в фокусе, мкм, и число точек по каждой оси
zCross	плоскость расчёта (0 — фокальная)
intensityFocus	`	Ex	²+	Ey	²+	Ez	²` в фокальной плоскости — из неё получается изображение
При правой круговой поляризации картины для +m и -m различаются: у m = -1
полный угловой момент равен 0, поэтому в центре яркое пятно, а не тёмная точка.

Генерация датасета
python generate_tc_dataset.py
Нужны numpy, scipy, pillow. Параметры: --n (изображений на класс),
--size (пикселей, по умолчанию 128), --tc 1 2 -1 -2, --colormap gray|viridis,
--seed, --out.

Интеграл считается квадратурой Гаусса–Лежандра (64×160 узлов) одним матричным
произведением. С integral2 из circularPar.m результат совпадает с точностью
~1e-13, а одна картина 128×128 считается за ~0.2 с.

Каждое изображение считается заново со своими случайными параметрами:

искажение пучка: ширина сектора delta ∈ [π/32, π/4], ориентация сектора beta ∈ [0, 2π);
геометрия: поворот, масштаб 0.85–1.15, эллиптичность 0.9–1.1, сдвиг центра до ±8 % кадра;
шумы: размытие, спекл, фон с градиентом, дробовой шум (30–3000 фотонов в максимуме),
гауссов шум считывания, битые пиксели.

Зеркальные отражения не применяются, потому что отражение меняет знак ТЗ. На
изображения не наносится подпись с меткой: иначе сеть научится читать текст,
а не распознавать вихрь.

Ось y направлена вверх, как в plotIntensityFocus (`axis xy`). Скрипты
generate_focus_noise_*.m сохраняли картинку через imwrite без переворота,
поэтому y у них направлена вниз и изображения зеркальны.
